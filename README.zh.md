# 交战：第三次世界大战——终局之战

[English](README.md)

以二战 2D 俯视拟真即时模拟《交战》（*Firefight*）规则为基础的现代战争重制模组工程。

## 关于本项目

新世纪以来，国际局势风云变幻，旧有秩序不断松动、崩解。假如某一天，第三次世界大战突然爆发，那将是人类历史上最后一场战争。这场战争不会停止，也不会因任何一方的退缩而终结——除非决出唯一的胜者。没有旁观者，也没有退路，整个世界都将被卷入这场不可逆的终局之战。

这正是本模组的故事背景与核心氛围。它是一个以现代与近未来为背景的大型 Firefight 模组，绝大部分内容由我们制作组自主开发完成。我们希望通过持续开发与打磨，围绕这一设定构建更完整的战场体验、阵营冲突与近未来战争氛围。

本项目采用 CC BY-SA 4.0 开放许可协议。

## 仓库结构

| 路径 | 内容 |
| --- | --- |
| `Assets/mod.txt` | 模组清单：国籍、装备表、单位与武器登记 |
| `Assets/Data/` | 单位、载具、武器与装备数据 |
| `Assets/Images/` | 单位、载具、车体、侧视、炮塔与制服图像 |
| `Assets/Sounds/` | 武器、爆炸、语音与音乐音效 |
| `CHANGELOG.md` | 版本更新说明与完整更新历史（英文版 `CHANGELOG.md`，中文版 `CHANGELOG.zh.md`） |
| `CREDITS.md` | 贡献者与赞助者 |
| `THIRD-PARTY-NOTICES.md` | 第三方素材与其许可证 |
| `docs/flow.md` | 仓库结构与数据流 |
| `LICENSE` | CC BY-SA 4.0 法律文本 |

`Assets/` 存放模组载荷，仓库根目录存放文档与许可文件。以本仓库作为模组目录进行打包时，须把 `Assets/` 的内容放到打包出的 `Mod/` 目录根部——游戏从该根部读取 `mod.txt`。
